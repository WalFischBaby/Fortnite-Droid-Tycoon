# WalFischBaby Droid Command v2.0

Fan-made Fortnite Star Wars Droid Tycoon tracker in the WalFischBaby neon command-center style.

## Included
- Droid Archive tracker
- Fusion Lab tracker and recipes
- Icon Vault tracker
- Rebirth Protocol with Cycle 1–5 guides
- Galaxy progress dashboard
- Commander rank
- Next Mission
- Achievements / Mission Log
- Recent activity
- Galaxy Scanner search
- Local save export / restore
- Mobile command navigation
- Secret WalFischBaby Easter egg
- Live Mythic / Kyber / Stellar blueprint drop timers
- Optional browser notifications and on-page/audio drop alerts

## Current blueprint rotation
- Kyber: every hour at :15
- Mythic: every hour at :55
- Stellar: every hour at :05 and :35

Timers use the visitor's local device clock so no manual daily reset is required. The schedule should be updated centrally in `common.js` if the game changes it in a future patch.
